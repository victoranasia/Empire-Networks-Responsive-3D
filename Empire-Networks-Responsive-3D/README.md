# Empire Networks — Responsive 3D Landing Page

This project recreates the supplied Empire Networks landing-page design as a real responsive website.

## Structure
- `index.html` — all page sections and content
- `styles.css` — desktop/tablet/mobile responsive styling
- `main.js` — Three.js 3D effects, navigation, counters, coverage form and scroll animations

## Run in VS Code
### Simplest
Open `index.html` with VS Code Live Server.

### No-install option
You can also open `index.html` directly in a modern browser. Three.js is loaded from jsDelivr, so an internet connection is needed for the 3D modules.

## 3D features
- Animated 3D particle/network field in the hero
- Multiple glowing network/data arcs
- Animated wireframe 3D globe with connection nodes
- Responsive WebGL resizing
- Scroll-reveal animations
- Animated network statistics

## Production replacements
Update these placeholders in `index.html`:
- `hello@empirenetworks.example`
- `+234 000 000 0000`
- Sample plan prices/specifications
- Sample testimonials
- Customer portal URL
- Coverage API/form endpoint
- Social-media URLs

The visual layout, typography hierarchy, colors, responsive breakpoints and section order are designed to follow the supplied reference.
